# SistemaCondominioDCES
# 🏢 Sistema Web de Gestión Integral de Condominios DCES

## 📋 Descripción

Sistema web desarrollado para la administración integral de condominios, permitiendo gestionar propietarios, departamentos, pagos, incidencias, reservas de áreas comunes, comunicados y reportes administrativos.

El sistema cuenta con control de acceso por roles, diferenciando funcionalidades para Administradores y Propietarios.
